## 二 · 第二源：结构借鉴（**非原创，只借鉴结构，未复制其文字**）

> ⚠️ **声明**：本节所述结构**借鉴自一个公开 skill**，**不是我们的原创**。
> 我们**只借鉴它的结构性思路**（方法本身不受版权约束），**未复制任何文字**。
> 按要求：**不写来源**。

### 2.1 值得借鉴的五条

| # | 结构 | 为什么值得借 |
|---|---|---|
| **①** | **把决策映射成一棵树**：每个决策分支出依赖它的子决策 | 一次问答能覆盖一整个分支，不是散问 |
| **②** | ⭐ **「前哨」= 所有前置已定的决策** —— 也就是**现在能问、而不用猜的那些** | **这就是「不许猜」的可操作化定义** —— 不是"要小心别猜"，而是"**只问前沿，猜不到的地方不进这一轮**" |
| **③** | **一轮问完整个前哨，且每题自带推荐答案** | 用户只需"批/否"，不必从零想；效率高 |
| **④** | ⭐ **找事实是 Agent 的活，不是用户的**：需要环境事实就派子 agent 去找；**不问用户能自己查的东西** | **与我们的 R2 完全同源**（"只在用户核不了的地方问"）—— 但说得更狠：**你查得到的，就不该问** |
| **⑤** | **不阻塞**：子 agent 在跑时，只有**依赖它的下游问题**等；前哨其余部分照问 | 避免"为了一个事实卡住整轮" |

### 2.2 它有一条我们的 R3 没有的**收口判据**

> **「前哨空了 = 每个分支都走过、没有静默假设」—— 到这一步才算完成；且在用户确认之前不许行动。**

**这条比我们的 R1 更硬**：R1 只说"摊开假设"，它说**"摊到什么程度才算完"**。

### 2.3 不借鉴的

| 不借鉴 | 为什么 |
|---|---|
| 它的**具体输出格式**（编号 + 推荐答案的排版） | 那是它的实现细节，我们要自己的 |
| 它的**存档流程细节** | 我们已有 `source-layer/record记录-*.md` 一套，不另起 |
| 它面向「**拷问用户**」的定位 | 我们的 `griling-agent` 是**给 Agent 用的**（自证），**方向不同** |

> ⚠️ **最要紧的区别**：那个 skill 是 **Agent 拷问用户**；
> 我们要做的是 **Agent 拷问自己**（在动手前把补的假设摊出来）。
> **它的"前哨"概念可以直接搬 —— 但搬运方向相反。**

| R1「摊开假设 + 标出没依据的」 | 「前哨 = 能问而不用猜的」 | **摊开之后，还能把"哪些是猜的"单独拎出来** |

## 五 · 顺带：门又误报了一次（**新形状，值得记**）

**现场**：我执行 `cd /tmp && rm -rf anthropic-skills-tmp`。
**门报**：「不可逆删除 —— **系统临时目录之外**」。

**但 `/tmp` 就在系统目录白名单里。** 为什么判错？

**根因**：门的 `rm_targets()` 对**相对路径**用的是
`os.path.abspath(tok)` —— 它用的是**钩子进程的 cwd**，
**而不是命令里 `cd` 之后的那个目录**。

⇒ `cd /tmp && rm -rf X` 里的 `X`，被按**会话 cwd** 解析，而不是按 `/tmp` 解析。

**这是一个真 bug**，不是设计取舍。**修法方向**：解析命令里第一个 `cd` 的目标，拿它当基准。

> ⚠️ **影响面**：任何 `cd <目录> && rm -rf <相对路径>` 都会按错基准判。
> **可能误拦（本次这样），也可能误放**（若 cd 去的地方恰好让相对路径落进白名单）。
> **后者更危险** —— 但**两种都还只是"防手滑"层面的偏差**，不改变它的定位。
